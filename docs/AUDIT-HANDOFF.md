## Release blockers

- [ ] **Fail closed on tool and provider isolation.** `crates/jugg-tools/src/sandbox.rs:35–68` silently falls back to a plain child when bubblewrap is unavailable; `crates/jugg-ai/src/cli.rs:84–99,174–185` uses separate controls for Claude and Codex. Require an approved production isolation profile for each execution path. Separate provider credentials from the rendering worker, use least privilege and an explicit environment/egress policy, and bound memory, output, time and subprocesses. **Done when:** missing isolation prevents tool startup, test fixtures confirm allowed read/write and network boundaries, and ordinary supported provider workflows still pass with credentials absent from logs.
- [ ] **Make production host routing explicit.** `app/src/web.rs:24–40,108–115` sends other hosts to admin and derives HTTPS redirects from the request hostname. Use the configured canonical admin, apex and www hosts; reject missing or unknown hosts, and define any trusted proxy behavior explicitly. **Done when:** routing tests cover each allowed host, missing/unknown hosts, canonical redirects and the development-only preview.
- [ ] **Make initial setup atomic and resumable.** `app/src/server.rs:724–785` commits brand/settings before creating the owner and recovery state; `app/src/api.rs:188–193` issues the session separately. Make persistent initialization transactional with a database-enforced single initialization; keep session delivery recoverable independently. **Done when:** simulated component failures leave consistent state, initialization retries safely, concurrent requests produce one owner, and an interrupted session response can be recovered with ordinary sign-in.

## Pilot delivery gates

Expose offsite status and age, surface copy failure and avoid premature retention pruning. **Done when:** failed remote delivery produces an observable failed status; an offsite bundle is restored onto clean Linux with the recovery key, and the running app can read restored records, open assets and serve the restored site.
